# Portfolio Website - Nitin Singh

A personal portfolio website showcasing my projects, skills, and contact information.

## Live Preview

Open `index.html` in your browser to view the site locally.

## Features
- Modern, professional theme with a custom header banner
- Project showcase with tech stack badges
- About, value, experience, and contact sections
- Responsive layout for mobile and desktop

## Tech Stack
- HTML
- CSS
- JavaScript

## Project Structure
- `index.html`
- `styles.css`
- `script.js`
- `your-image.png`

## How To Run Locally
1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Customization
- Update your info in `index.html`.
- Change colors and typography in `styles.css`.
- Replace images in the root folder and update their paths in `index.html`.
